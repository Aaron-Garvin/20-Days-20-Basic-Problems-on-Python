## 🧠 About

This project is a beginner-friendly Python game that demonstrates core programming concepts like loops, conditionals, randomness, and input validation — all wrapped in a classic game everyone knows. It runs entirely in the terminal with no external dependencies.

---

## ✨ Features

- ✅ Play unlimited rounds until you choose to quit
- ✅ Computer picks randomly — fair every time
- ✅ Live result after every round — Win, Lose or Tie
- ✅ Full score tracking — yours and the computer's
- ✅ Input validation — ignores invalid entries gracefully
- ✅ Case-insensitive input — type `ROCK`, `rock` or `Rock`, all work
- ✅ Clean final summary displayed when you quit

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed on your machine
- No external libraries required

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Aaron-Garvin/20-Days-20-Basic-Problems-on-Python.git
   cd "20-Days-20-Basic-Problems-on-Python/03. ROCK, PAPER, SCISSORS-GAME"
   ```

2. **Run the game:**
   ```bash
   python "03. Rock, Paper, Scissors-Game.py"
   ```

## 🎮 How to Play

1. Run the script in your terminal.
2. Type `Rock`, `Paper`, or `Scissors` and press **Enter**.
3. The computer picks randomly — result is shown instantly.
4. Keep playing as many rounds as you want.
5. Type `Q` to quit — your final score is displayed.

**Example session:**

```
Type Rock/Paper/Scissors or Q to quit: rock
Computer picked scissors.
You won!

Type Rock/Paper/Scissors or Q to quit: paper
Computer picked paper.
You tie with computer!

Type Rock/Paper/Scissors or Q to quit: scissors
Computer picked rock.
You lost!

Type Rock/Paper/Scissors or Q to quit: q
You won 1 times.
Computer won 1 times.
Goodbye!
```

## 🧠 Code Overview

| Component | Description |
|-----------|-------------|
| `random.randint(0, 2)` | Randomly picks the computer's move |
| `options[]` | Maps number (0, 1, 2) to rock, paper, scissors |
| `.lower()` | Makes input case-insensitive |
| `while True` + `break` | Keeps the game running until user quits |
| `user_wins` / `computer_wins` | Tracks score across all rounds |

### Key Python Concepts Used

- **`random` module** — for generating the computer's random pick
- **`while True` + `break`** — for the main game loop
- **`continue`** — to skip invalid inputs silently
- **`.lower()`** — for case-insensitive input handling
- **Conditionals** — to determine win, lose, or tie each round
