## 🧠 About

This project is a beginner-friendly Python quiz application designed to make learning core computer science concepts engaging and accessible. It runs entirely in the terminal — no dependencies, no setup hassle.

---

## ✨ Features

- ✅ 6 multiple-answer questions covering key CS concepts
- ✅ Case-insensitive input — no need to worry about capitalisation
- ✅ Accepts multiple valid answers for flexible questions
- ✅ Live score tracking with a final result at the end
- ✅ Clean, readable code — great for beginners to study

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed on your machine
- No external libraries required

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/computer-quiz.git
   cd computer-quiz
   ```

2. **Run the quiz:**
   ```bash
   python quiz.py
   ```

---

## 🎮 How to Play

1. Run the script in your terminal.
2. Type `yes` when prompted to start the game.
3. Answer each question by typing your response and pressing **Enter**.
4. Your score is tallied automatically and displayed at the end.

**Example session:**
```
Welcome to my computer quiz!
Want to test your computer Knowledge? yes
Okay! Let's play :)

Q1. What does CPU stand for? central processing unit
Correct!
...
Quiz over! You scored 5/6
```
